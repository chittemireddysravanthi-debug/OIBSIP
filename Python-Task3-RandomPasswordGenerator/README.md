# Random Password Generator

## Oasis Infobyte Internship – Python Programming

### Project Description
A Python application that generates random passwords based on the user's preferred length and character types.

### Features
- Custom password length (minimum 8 characters).
- Uppercase letters.
- Lowercase letters.
- Numbers.
- Special symbols.
- Requires at least two character types.
- Input validation.
- Option to generate multiple passwords.

### Technologies Used
- Python 3
- random module
- string module

### How to Run
```bash
py password_generator.py
```
