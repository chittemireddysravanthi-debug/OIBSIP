# Basic Weather App – Python

## Project Description
A Python-based weather application that fetches real-time weather information for a city using the Open-Meteo API.

## Features
- Search weather by city name.
- Display current temperature in Celsius.
- Display feels-like temperature.
- Display humidity.
- Display wind speed.
- Display weather conditions.
- Handle invalid city names and API errors.

## Technologies Used
- Python
- Requests library
- Open-Meteo API
- JSON

## Installation

Install the required library:

```bash
py -m pip install requests
```

## How to Run

```bash
py weather_app.py
```

Enter a city name when prompted.

## API Used
- Geocoding API: https://geocoding-api.open-meteo.com/
- Weather API: https://api.open-meteo.com/
