
# BMI Calculator

## Oasis Infobyte Internship - Python Programming

### Project Description
A simple Python application that calculates Body Mass Index (BMI) using weight and height.

### Features
- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI.
- Displays BMI up to two decimal places.
- Categorizes BMI into Underweight, Normal Weight, Overweight, and Obese.
- Handles invalid and negative inputs.

### Technologies Used
- Python 3
- VS Code

### BMI Formula
BMI = Weight / (Height * Height)

### How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the command:

py bmi_calculator.py
